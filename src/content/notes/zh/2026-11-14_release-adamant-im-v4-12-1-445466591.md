版本 v4.12.1 基于 v4.12.0 (`dfe094d3`) 从主分支 (`074db965`) 发布。通过 68 次提交和 12 个合并的拉取请求，此版本强化了跨托管目标的 CSP 和安全响应头，消除了 Web3 验证中运行时的 `eval`/`Function` 路径，更新了 ADAMANT Node REST/WebSocket 架构及最低 node/IPFS API 版本，将本地化扩展至包括阿拉伯语 RTL 在内的八种语言，修复了具有严格单节点亲和性的绑定加密交易历史分页，在登录和设置界面添加了构建标识和缓存重置控件，并更新了 Android 16 和 macOS CI 打包配置。

### 安全与 CSP 强化

统一的安全响应头 (`#1006`) 将 `PWA_SECURITY_HEADERS` 定义为 `vite-config/plugins/cspHardeningPlugin.ts` 中的单一事实来源 (`frame-ancestors 'none'`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-XSS-Protection: 0`)。`vercel.json` 中的全捕获规则将 `report-uri /api/csp-report` 限制为 `dev.adamant.im` 和 Vercel 预览主机，`gh-pages` 被排除在 Vercel 部署之外，且此版本随附了相应的 `deploy/nginx/security-headers.conf` 和 `deploy/nginx/pwa-site.conf.example` 头部/部署规范。

供应链与依赖项强化 (`#990`, `#1029`) 添加了 `node scripts/check-dependency-release-age.mjs`、`.npmrc` (`min-release-age=7`)、`.github/dependency-release-age-exceptions.json`，并在安全 CI 中设置了 Dependabot 冷却期（npm 为 8 天，GitHub Actions 为 7 天）。

无 `eval` 的 Zod 4 和依赖项补救 (`#1029`) 为 `web3-validator` 使用了 Zod 4 (`src/lib/configureZod.ts` 中的 `config({ jitless: true })`)，为 `web3-eth-abi` 使用了 `abitype`，移除了编译器入口点，并在 `cspHardeningPlugin.ts` 中针对 `Function` 别名扩展了包门控。核心运行时和构建依赖项已更新 (`dompurify`, `vue`, `vuetify`, `vue-router`, `vue-i18n`, `pinia`, `axios`, `marked`, `vite`, `electron`, `@capacitor/*`)，并移除了 `b64-to-blob`, `file-saver`, 和 `jest-serializer-vue`。

Playwright CI 凭据与制品隔离 (`#999`) 在 Playwright CI 中拒绝配置的实时账户密码，在 `playwright.config.ts` 中禁用了 CI 追踪、截图、视频和 HTML/JSON 报告器，并停止在 `.github/workflows/playwright-ui-smoke.yml` 中上传 Playwright 报告制品。

Electron 主包安全性 (`9cf71bc2`) 仅在 `DEV` 模式下动态导入 `electron-devtools-installer`，将其移至 `devDependencies`，并通过 `scripts/electron/verifyMainBundle.mjs` 在 `electron:build:prepare` 期间验证 `dist-electron/main.js`。

### API 与架构更新

ADAMANT Node API 架构 (`src/lib/schema/schema.json`) 在 `/chats/get` 和聊天检索端点上，将布尔值 `withoutDirectTransfers` 替换为整数枚举 `[0, 1]` 参数 `includeDirectTransfersInChatRooms` (`default: 1`) 和 `includeDirectTransfersInChats` (`default: 0`) (`#984`)。

ADAMANT WebSocket 订阅 (`src/lib/sockets.js`) 在账户解锁时使用活跃的 ADM 节点立即连接，并为 `CHAT_TRANSACTION_TYPES` (`[Transactions.SEND, Transactions.CHAT_MESSAGE]`, 类型 `0` 和 `8`) 发出 `types` (`#984`)。

钱包 OpenAPI 和最低 API 版本 (`src/types/wallets/index.ts`, `adamant-wallets` `9a7df1f`) 为 `Service` 添加了可选的 `minVersion?: string`，将主网、测试网和 Tor 的 `adm.nodes.minVersion` 提高至 `0.10.0` (`#984`)，将 `adm.services.ipfsNode.minVersion` 设置为 `0.1.0`，并更新了 `src/lib/nodes/ipfs/index.ts` 中的 `IpfsClient` 实例化以读取 `ipfsService.minVersion` 而非 `adm.services.minVersion` (`#1003`)。`adamant-wallets` 更新至 `9a7df1f` 后，重新生成了 `src/config/mainnet.json`、`src/config/testnet.json` 和 `src/lib/constants/cryptos/data.json` 的回退 IP。

ETH PostgREST 索引器查询 (`src/lib/nodes/eth-indexer/EthIndexerClient.ts`) 确保每个 `/ethtxs` 请求都包含 `limit` (`limit ?? 25`)，将原生 ETH 历史拆分为两个有界的索引查询 (`txfrom=eq.{addr}&contract_to=eq.` 和 `txto=eq.{addr}&contract_to=eq.`) 并在客户端合并去重，保留了 `from`/`to` 时间边界，并添加了 `getTimestampGroup` 以解决分页边界冲突 (`#992`)。

### 本地化与 RTL 支持

八语言对齐 (`#998`) 添加了西班牙语 (`es`)、法语 (`fr`)、日语 (`ja`) 和阿拉伯语 (`ar`)，审查并更新了德语 (`de`)、俄语 (`ru`) 和简体中文 (`zh`)，将所有八个语言环境的 JSON 文件与 `en.json` 对齐，将硬编码字符串提取为语言环境键，并在 `PasswordSetDialog.vue` 中使用 `<i18n-t>` 插槽插值。

集中式 i18n 运行时与复数化 (`#998`) 合并了 `src/i18n.js` 中的 `applyLocale()`，以同步 `vue-i18n`、`dayjs`、Vuetify 语言环境以及文档的 `lang`/`dir`。它修正了 `pluralRules`（包括阿拉伯语、法语和俄语 `> 100` 的 teen 规则），在没有保存偏好设置时从 `navigator.languages` 本地初始化浏览器语言，并使用 `ar-u-nu-latn` 格式化阿拉伯语日期。

完整的阿拉伯语 RTL 布局 (`#998`) 配置了 Vuetify `rtl: { ar: true }`，使用 `a-directional-icon` 镜像方向性图标，在聊天/钱包/设置视图中采用 CSS 逻辑属性，在用户创作的消息和聊天编辑器上设置 `dir="auto"`，同时保留密码短语的 LTR 渲染，并添加了 `RtlUiContract.spec.js` 和 `chat-rtl-layout-regression.spec.ts`。

### 消息传递、交易历史与节点可靠性

直接 ADM 转账与预览同步 (`#984`) 在聊天、聊天室和 WebSocket 流程中摄入传入的 0 型 ADM 转账，处理去重后的未读状态，在省略时推导回退确认状态，更新了 `AChatTransaction.vue`、`ChatPreview.vue`、`AdmTransaction.vue` 和 `TransactionListItem.vue`，并通过 `scripts/wallets/sourceBranch.mjs` 将 PWA 分支映射到 `adamant-wallets/dev` 与 `master`。

有界分页与严格单节点亲和性 (`#992`) 更新了 ETH/ERC-20、BTC (`walkHistory`、递归/循环保护、页面预算、每个节点的 `exhausted` 跟踪) 以及 DOGE（确认非 `PENDING` 偏移计算、重叠重读、双花容错）的历史分页，使每个请求窗口都固定在活跃的索引器上，无需跨运营商地址扇出。DASH 历史加载器被包裹在 `try ... finally` 中，并添加了 `src/lib/live-history-pagination.env.spec.ts`。

IndexedDB 模块清理 (`#992`) 在 `src/lib/idb/state.js` 中引入了 `toPersistedModule`，以便持久化的加密模块省略 `transactions`，并在保存时重置 `bottomReached`、`oldTxState`、`newTxCatchUp` 和 `historySession`。

HTTP 附件与通知 (`#989`) 在 `src/lib/files/ipfs.ts` 中添加了 `@noble/hashes` SHA-256 多重哈希回退（当普通 HTTP 源上缺少 `crypto.subtle` 时），安全地解析 `src/lib/notifications.js` 中的 `$t`，并在 `src/App.vue` 中保留 `Notifications` 实例以进行卸载清理。

### 构建标识、网络配置与平台打包

登录与设置构建标识 (`#996`) 通过 `vite-config/plugins/buildInfoPlugin.ts` (`virtual:adamant-build-info`) 注入清理后的构建元数据 (`version`, `branch`, `commit`, `prNumber`, `author`, `buildDate`, `isTestnet`)，在 `/login` 和 `/options` 上渲染 `BuildInfo.vue` 和 `BuildInfoDialog.vue`，提供 Service Worker + CacheStorage 强制刷新操作（保留存储的凭据/账户数据），并用英雄芯片和角标标记测试网构建。

隔离的网络配置 (`#986`) 用共享的 `mainnet.json` 替换了 `development.json` 和 `production.json`，通过 `virtual:adamant-network-config` 打包单一配置，强制执行严格的 Vite 模式验证，拒绝 `src/config` 中意外的 JSON 文件和跨网络端点泄漏，在 CI 工作流中强制执行 `npm run wallets:data:check`，并将贡献者/构建文档整合到 `CONTRIBUTING.md` 中。

Android 16 和 Electron macOS CI (`b378c2f8`, `#1035`) 将 Android `compileSdkVersion`/`targetSdkVersion` 提高至 `36`，`minSdkVersion` 至 `24`，AGP 至 `8.13.0`，Gradle 至 `8.14.3`，`cordovaAndroidVersion` 至 `14.0.1` (`versionCode` `41201`)。版本元数据提升至 `4.12.1`。此版本在 `.github/workflows/electron-mac.yml` 中将 `APPLE_NOTARIZE` 设置为 `'false'`，同时保留 Developer ID 签名，并在 `CONTRIBUTING.md` 中记录了 Gatekeeper **仍要打开 (Open Anyway)** 的说明。

### 重大变更

最低节点和服务 API 版本 (`#984`, `#1003`, `98fc3815`) 现在将 API 低于 `0.10.0` 的 ADM 节点从所有 ADM 请求中排除，将低于 `0.1.0` 的 IPFS 节点标记为 `unsupported_version`，并用重定位的替代方案替换了旧的回退 IP 地址 (`endless`, `testnode1`, `testnode3`, `dschubba`)。

macOS CI 公证已禁用 (`#1035`)。macOS 制品在没有 Apple 公证的情况下以 Developer ID 签名发布 (`APPLE_NOTARIZE: 'false'`)，因此 Gatekeeper 需要通过 **系统设置 → 隐私与安全性 → 仍要打开** 允许应用一次。

严格的 CSP 响应头 (`#1006`) 通过全捕获 `vercel.json` 规则和 `deploy/nginx/security-headers.conf` 强制执行，包含 `frame-ancestors 'none'`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, 和 `X-XSS-Protection: 0`。

`development.json` 和 `production.json` 配置文件已被移除 (`#986`)。运行时配置导入继续通过由 `src/config/mainnet.json` 支持的 `@/config` 进行，不支持的 Vite 模式或 `src/config` 中意外的 JSON 文件会导致构建失败。

包管理器固定为 `npm@12.2.2`，具有 7 天 npm 隔离期和 Zod 4 验证 (`#1029`)。早于 7 天的依赖版本在安全 CI 中会失败（除非被豁免），且 Web3 Zod 格式错误会省略原始输入值。

Android 16 目标 (`b378c2f8`) 将 `minSdkVersion` 从 `23` 提高至 `24` (Android 7.0)，`compileSdkVersion` 和 `targetSdkVersion` 设置为 `36`。

IndexedDB 加密状态清理 (`#992`) 意味着持久化的加密模块在保存时省略 `transactions` 并重置分页会话游标。
