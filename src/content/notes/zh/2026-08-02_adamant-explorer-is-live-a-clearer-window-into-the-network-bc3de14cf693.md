全新的 ADAMANT Explorer 已在 explorer.adamant.im 上线，为您提供更快速、更直观的方式来追踪网络动态。区块链浏览器是让网络数据变得易于理解的工具，它将晦涩的标识符转化为可读的区块、交易和账户信息。ADAMANT Explorer 的重构旨在确保用户能够毫无阻碍地验证网络活动。

主屏幕显示主网状态、当前链高度以及 ADM 供应量。“最新操作”（Latest operations）信息流将实时的链上活动转化为易读格式，让转账、消息、投票和注册等操作一目了然。统一的搜索栏允许用户查找区块、交易、地址或委托人，并直接跳转至相关记录，无需手动解析 URL 结构。

重新设计的区块列表提供了关键的导向数据，包括 ID、高度、时间戳、交易数量、锻造委托人、金额以及锻造奖励。详情视图保留了完整的记录，以便进行更深入的调查。这种设计在确保重要上下文可见的同时，也保持了原始链数据的可访问性。

ADAMANT 是由社区运营的基础设施，其浏览器也是开源的，构建于公共 ADAMANT 节点接口之上。它将实时网络更新与基于 API 的详情视图相结合，确保在节点保持区块链状态权威性的同时，不断变化的网络依然清晰可读。这为用户提供了一个由独立节点运营的公共网络窗口，而无需依赖私有仪表板或延迟的数据源。
