### 可验证构建与零妥协的浏览器安全性

在仅客户端运行的加密通讯软件中，密钥严格保存在设备本地，浏览器或 WebView 运行时本身即是威胁模型的一部分。ADAMANT v4.12.1 采用统一的严格内容安全策略（CSP）和安全响应标头基准——`frame-ancestors 'none'`、`X-Frame-Options: DENY`、`X-Content-Type-Options: nosniff` 以及 `Referrer-Policy: no-referrer`——并由自动化生产探针持续强制执行。Web3 验证已迁移至无 eval 的 Zod 4 (jitless) 和 abitype，消除了运行时 eval 和动态 `Function` 构建，并在发布前通过严格的构建门禁进行验证。

登录和设置页面中的“构建标识”（Build Identity）指示器允许您查看确切的版本、源码分支、提交哈希、作者和构建时间戳，并支持在不触碰密钥或加密本地存储的情况下，安全地强制刷新缓存的应用资源。测试网镜像带有明确的 TESTNET 标记，确保测试资金与主网会话不会混淆。

### 八种完整语言支持与阿拉伯语 RTL 适配

ADAMANT 的完整语言支持从四种翻倍至八种（每种语言包含 418 个匹配的界面键）。阿拉伯语现已支持完整的从右向左（RTL）布局、镜像方向图标、逻辑 CSS 间距、用于自然混合方向输入的 `dir="auto"` 组合框对齐，以及用于日期和余额的纯拉丁数字（`ar-u-nu-latn`）。西班牙语、法语和日语均为新增语言，并已覆盖所有对话框、钱包界面和错误消息。英语、德语、俄语和简体中文已完成审计，并修正了复数规则。语言偏好通过浏览器设置在本地检测，不会向外发送任何遥测数据。

### 更可靠的多节点聊天、转账与钱包历史记录

由于 ADAMANT 直接连接到独立的社区节点和索引器，而非单一的企业服务器，系统的韧性取决于客户端处理部分故障和分页的精细程度。更新后的 ADAMANT 节点 REST/WebSocket 订阅（`includeDirectTransfers` 过滤器和 `[0, 8]` 套接字事件）确保了传入的直接 ADM 转账能在聊天列表和对话气泡中及时刷新。

原生的以太坊查询现已拆分为边界明确的索引 PostgREST 查询，并在客户端合并，从而避免索引器停滞。BTC、DOGE 和 ETH 的分页功能将每次滚动会话固定在单个活跃节点上，避免将您的钱包地址广播给多个运营商。IndexedDB 中陈旧的持久化分页游标会在保存时自动清理。

过时的 ADM 节点（< 0.10.0）和 IPFS 节点（< 0.1.0）会在请求静默失败前被明确标记并过滤，同时更新了来自 adamant-wallets 的备用节点端点。即使在 Web Crypto 不可用的普通 HTTP .onion 镜像上，附件 CID 哈希计算也能通过纯 JS SHA-256 备用方案完成。

### 平台更新与 Apple 相关情况

v4.12.1 针对 Android 16 (API 36) 进行了优化，提供已签名的 APK 和 App Bundle (versionCode 41201)，更新了桌面端依赖项（Electron、Vite、Vue、Vuetify），并收紧了生产环境的 Electron 打包，确保开发工具不会包含在生产构建中。

由于 Apple 封禁了 ADAMANT 开发者账号，iOS App Store 版本目前无法更新或通过 Apple 商店安装。原生的 macOS 桌面应用（x64、Apple Silicon 和通用 .dmg）仍会构建、使用开发者 ID 签名并发布在 GitHub 上，只是没有经过 Apple 公证。首次打开应用后，请前往“系统设置”→“隐私与安全性”→“仍要打开”即可正常运行。

发布说明和二进制文件可在 [v4.12.1 GitHub 发布页面](https://github.com/Adamant-im/adamant-im/releases/tag/v4.12.1) 获取。
