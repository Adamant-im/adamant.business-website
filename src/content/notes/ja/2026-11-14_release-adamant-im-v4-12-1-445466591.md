リリース v4.12.1 は v4.12.0 (`dfe094d3`) をベースに master (`074db965`) からリリースされました。68件のコミットと12件のプルリクエストを含み、本リリースでは、ホスティングターゲット全体でのCSPおよびセキュリティレスポンスヘッダーの強化、Web3バリデーションにおけるランタイム `eval`/`Function` パスの排除、ADAMANT Node REST/WebSocketスキーマと最小node/IPFS APIバージョンの更新、アラビア語のRTL（右書き）を含む8言語へのローカライズ拡大、厳格なシングルノードアフィニティによる暗号資産取引履歴のページネーション修正、ログインおよび設定画面へのビルド識別情報とキャッシュリセット制御の追加、Android 16およびmacOS CIパッケージングの更新を行いました。

### セキュリティとCSPの強化

統合されたセキュリティレスポンスヘッダー (`#1006`) では、`vite-config/plugins/cspHardeningPlugin.ts` 内で `PWA_SECURITY_HEADERS` を唯一の信頼できる情報源として定義しています (`frame-ancestors 'none'`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-XSS-Protection: 0`)。`vercel.json` の包括的なルールにより、`report-uri /api/csp-report` は `dev.adamant.im` および Vercel プレビューホストに制限され、`gh-pages` は Vercel デプロイから除外されます。また、本リリースには対応するヘッダーおよびデプロイ仕様を記載した `deploy/nginx/security-headers.conf` と `deploy/nginx/pwa-site.conf.example` が同梱されています。

サプライチェーンおよび依存関係の強化 (`#990`, `#1029`) として、`node scripts/check-dependency-release-age.mjs`、`.npmrc` (`min-release-age=7`)、`.github/dependency-release-age-exceptions.json` が追加され、セキュリティCIにおけるDependabotのクールダウン期間（npmは8日、GitHub Actionsは7日）が設定されました。

`eval` を排除した Zod 4 への移行と依存関係の修正 (`#1029`) では、`web3-validator` に Zod 4 (`src/lib/configureZod.ts` で `config({ jitless: true })`) を使用し、`web3-eth-abi` に `abitype` を採用しました。コンパイラのエントリポイントを削除し、`cspHardeningPlugin.ts` における `Function` エイリアスに対するバンドルゲートを拡張しています。主要なランタイムおよびビルド依存関係を更新し (`dompurify`, `vue`, `vuetify`, `vue-router`, `vue-i18n`, `pinia`, `axios`, `marked`, `vite`, `electron`, `@capacitor/*`)、`b64-to-blob`, `file-saver`, `jest-serializer-vue` を削除しました。

Playwright CIの認証情報とアーティファクトの分離 (`#999`) により、Playwright CIで設定済みのライブアカウントパスフレーズを拒否し、`playwright.config.ts` でCIトレース、スクリーンショット、動画、HTML/JSONレポーターを無効化しました。また、`.github/workflows/playwright-ui-smoke.yml` でのPlaywrightレポートアーティファクトのアップロードを停止しました。

Electronメインバンドルの安全性 (`9cf71bc2`) として、`electron-devtools-installer` を `DEV` モードでのみ動的にインポートするように変更し、`devDependencies` に移動しました。また、`scripts/electron/verifyMainBundle.mjs` を通じて `electron:build:prepare` 実行時に `dist-electron/main.js` を検証します。

### APIおよびスキーマの更新

ADAMANT Node APIスキーマ (`src/lib/schema/schema.json`) では、`/chats/get` およびチャット取得エンドポイントにおいて、ブール値の `withoutDirectTransfers` を廃止し、整数列挙型 `[0, 1]` のパラメータ `includeDirectTransfersInChatRooms` (`default: 1`) および `includeDirectTransfersInChats` (`default: 0`) に置き換えました (`#984`)。

ADAMANT WebSocketサブスクリプション (`src/lib/sockets.js`) は、アカウントロック解除時にアクティブな ADM ノードへ遅延なく接続し、`CHAT_TRANSACTION_TYPES` (`[Transactions.SEND, Transactions.CHAT_MESSAGE]`, 型 `0` および `8`) の `types` を出力します (`#984`)。

ウォレットOpenAPIおよび最小APIバージョン (`src/types/wallets/index.ts`, `adamant-wallets` `9a7df1f`) では、`Service` にオプションの `minVersion?: string` を追加しました。メインネット、テストネット、Tor全体で `adm.nodes.minVersion` を `0.10.0` に引き上げ (`#984`)、`adm.services.ipfsNode.minVersion` を `0.1.0` に設定しました。また、`src/lib/nodes/ipfs/index.ts` における `IpfsClient` のインスタンス化を、`adm.services.minVersion` ではなく `ipfsService.minVersion` を読み取るように更新しました (`#1003`)。`adamant-wallets` の `9a7df1f` への更新により、`src/config/mainnet.json`, `src/config/testnet.json`, および `src/lib/constants/cryptos/data.json` のフォールバックIPが再生成されます。

ETH PostgRESTインデクサーのクエリ (`src/lib/nodes/eth-indexer/EthIndexerClient.ts`) では、すべての `/ethtxs` リクエストに `limit` (`limit ?? 25`) を含めるようにしました。ネイティブETH履歴を2つの境界付きインデックスクエリ (`txfrom=eq.{addr}&contract_to=eq.` と `txto=eq.{addr}&contract_to=eq.`) に分割し、クライアント側で `txhash` によりマージおよび重複排除を行います。また、`from`/`to` の時間境界を保持し、ページネーション境界の衝突を解決するために `getTimestampGroup` を追加しました (`#992`)。

### ローカライズとRTLサポート

8言語対応 (`#998`) として、スペイン語 (`es`)、フランス語 (`fr`)、日本語 (`ja`)、アラビア語 (`ar`) を追加しました。ドイツ語 (`de`)、ロシア語 (`ru`)、簡体字中国語 (`zh`) を見直し更新し、8つのロケールJSONファイルすべてを `en.json` に合わせました。ハードコードされた文字列をロケールキーに抽出し、`PasswordSetDialog.vue` で `<i18n-t>` スロット補間を使用しています。

集中型i18nランタイムと複数形対応 (`#998`) により、`src/i18n.js` の `applyLocale()` を統合し、`vue-i18n`、`dayjs`、Vuetifyロケール、およびドキュメントの `lang`/`dir` を同期させました。`pluralRules` を修正し（アラビア語、フランス語、ロシア語の `> 100` などのルールを含む）、保存された設定がない場合は `navigator.languages` からブラウザ言語をローカルで初期化し、アラビア語の日付を `ar-u-nu-latn` を使用してフォーマットします。

完全なアラビア語RTLレイアウト (`#998`) として、Vuetify `rtl: { ar: true }` を設定し、`a-directional-icon` で方向アイコンを反転させました。チャット/ウォレット/設定ビュー全体でCSS論理プロパティを採用し、ユーザーが作成したメッセージとチャットコンポーザーに `dir="auto"` を設定しつつ、パスフレーズのLTRレンダリングを維持しています。また、`RtlUiContract.spec.js` と `chat-rtl-layout-regression.spec.ts` を追加しました。

### メッセージング、取引履歴、ノードの信頼性

直接的な ADM 送金とプレビュー同期 (`#984`) により、チャット、チャットルーム、WebSocketフロー全体で受信した型0の ADM 送金を取り込み、重複排除された未読処理を行います。省略時のフォールバック確認状態を導出し、`AChatTransaction.vue`, `ChatPreview.vue`, `AdmTransaction.vue`, `TransactionListItem.vue` を更新しました。また、`scripts/wallets/sourceBranch.mjs` を通じてPWAブランチを `adamant-wallets/dev` または `master` にマッピングします。

境界付きページネーションと厳格なシングルノードアフィニティ (`#992`) により、ETH/ERC-20、BTC (`walkHistory`、再帰/サイクルガード、ページ予算、ノードごとの `exhausted` 追跡)、および DOGE (確定した非 `PENDING` オフセット計算、重複再読み込み、二重支払い許容) の履歴ページネーションを更新し、すべてのリクエストウィンドウがクロスオペレーターのアドレスファンアウトなしでアクティブなインデクサーに固定されるようにしました。DASH履歴ローダーを `try ... finally` でラップし、`src/lib/live-history-pagination.env.spec.ts` を追加しました。

IndexedDBモジュールのサニタイズ (`#992`) として、`src/lib/idb/state.js` に `toPersistedModule` を導入し、永続化された暗号モジュールが `transactions` を除外し、保存時に `bottomReached`, `oldTxState`, `newTxCatchUp`, `historySession` をリセットするようにしました。

HTTP添付ファイルと通知 (`#989`) として、プレーンなHTTPオリジンで `crypto.subtle` が存在しない場合に `src/lib/files/ipfs.ts` で `@noble/hashes` SHA-256 マルチハッシュフォールバックを追加しました。`src/lib/notifications.js` で `$t` を安全に解決し、`src/App.vue` でアンマウント時のクリーンアップのために `Notifications` インスタンスを保持します。

### ビルド識別情報、ネットワーク設定、プラットフォームパッケージング

ログインおよび設定画面のビルド識別情報 (`#996`) として、`vite-config/plugins/buildInfoPlugin.ts` (`virtual:adamant-build-info`) を介してサニタイズされたビルドメタデータ (`version`, `branch`, `commit`, `prNumber`, `author`, `buildDate`, `isTestnet`) を注入します。`/login` および `/options` で `BuildInfo.vue` と `BuildInfoDialog.vue` をレンダリングし、Service Worker + CacheStorage の強制更新アクション（保存された認証情報/アカウントデータは保持）を提供し、テストネットビルドをヒーローチップとコーナーバッジでマークします。

分離されたネットワーク設定 (`#986`) により、`development.json` と `production.json` を共有の `mainnet.json` に置き換え、`virtual:adamant-network-config` を介して単一の設定をバンドルします。厳格なViteモード検証を強制し、`src/config` 内の予期しないJSONファイルやネットワーク間エンドポイントのリークを拒否し、CIワークフローで `npm run wallets:data:check` を強制し、貢献者/ビルドドキュメントを `CONTRIBUTING.md` に統合しました。

Android 16およびElectron macOS CI (`b378c2f8`, `#1035`) では、Android の `compileSdkVersion`/`targetSdkVersion` を `36` に、`minSdkVersion` を `24` に、AGP を `8.13.0` に、Gradle を `8.14.3` に、`cordovaAndroidVersion` を `14.0.1` (`versionCode` `41201`) に引き上げました。バージョンメタデータは `4.12.1` になります。本リリースでは、`.github/workflows/electron-mac.yml` で `APPLE_NOTARIZE: 'false'` を設定しつつ、Developer ID署名は維持し、Gatekeeperの **「このまま開く (Open Anyway)」** 手順を `CONTRIBUTING.md` に記載しています。

### 破壊的変更

最小ノードおよびサービスAPIバージョン (`#984`, `#1003`, `98fc3815`) により、API `0.10.0` 未満の ADM ノードはすべての ADM リクエストから除外され、`0.1.0` 未満の IPFS ノードは `unsupported_version` とマークされます。また、古いフォールバックIPアドレス (`endless`, `testnode1`, `testnode3`, `dschubba`) は移転先の代替アドレスに置き換えられました。

macOS CIの公証は無効化されました (`#1035`)。macOSアーティファクトはAppleの公証なしでDeveloper ID署名されて出荷されるため、Gatekeeperを利用する場合、**システム設定 → プライバシーとセキュリティ → このまま開く** からアプリを許可する必要があります。

厳格なCSPレスポンスヘッダー (`#1006`) が、包括的な `vercel.json` ルールと `deploy/nginx/security-headers.conf` を通じて強制されます (`frame-ancestors 'none'`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-XSS-Protection: 0`)。

`development.json` および `production.json` 設定ファイルは削除されました (`#986`)。ランタイム設定のインポートは `src/config/mainnet.json` をバックエンドとする `@/config` を通じて継続されます。サポートされていないViteモードや `src/config` 内の予期しないJSONファイルはビルドエラーとなります。

パッケージマネージャーは `npm@12.2.2` に固定され、7日間のnpm検疫とZod 4検証が導入されました (`#1029`)。7日未満の依存関係バージョンは、例外を除きセキュリティCIで失敗し、Web3 Zodフォーマットエラーは生の入力値を除外します。

Android 16ターゲット (`b378c2f8`) では、`minSdkVersion` が `23` から `24` (Android 7.0) に引き上げられ、`compileSdkVersion` と `targetSdkVersion` が `36` に設定されました。

IndexedDB暗号状態のサニタイズ (`#992`) により、永続化された暗号モジュールは `transactions` を除外し、保存時にページネーションセッションカーソルをリセットします。
