## Проблема ликвидности токенов

Для основателей криптопроектов листинг на централизованной бирже часто открывает суровую реальность: токен без ликвидности фактически мертв. Без постоянной ликвидности и видимого объема торгов проекты теряют позиции в агрегаторах, арбитражные боты расширяют спреды, а розничные покупатели уходят из-за проскальзывания цены. Традиционный подход заключается в найме маркетмейкингового агентства, выплате ежемесячных комиссий от $5 000 до $30 000 и передаче токенов и стейблкоинов под контроль третьих лиц. Многие проекты уже столкнулись с тем, что их токены распродавались, а маркетмейкеры исчезали в периоды рыночной нестабильности.

Альтернативой является автономный самохостинг-маркетмейкинг. С помощью ADAMANT TradeBot v10.0.0 вы можете запустить профессиональный, полностью автоматизированный маркетмейкер на VPS за $5 в месяц или в контейнере Docker менее чем за пять минут, не передавая никому права на свои токены.

## Некастодиальная архитектура

Основная концепция — полная финансовая независимость. ADAMANT TradeBot работает исключительно в вашей изолированной среде. Бот требует только базовые API-права на чтение и торговлю; права на вывод средств строго отключены и запрещены. Вы никогда не отправляете токены или стейблкоины в ADAMANT, агентствам или смарт-контрактам. Токены никогда не покидают ваш биржевой аккаунт, а все расчеты ордеров, алгоритмические спреды и сверка балансов выполняются локально. ## Четыре алгоритмических движка

Версия с открытым исходным кодом включает четыре синхронизированных движка, которые совместно управляют всеми аспектами маркетмейкинга.

Движок **Trader** генерирует стабильный, естественный объем торгов, выполняя сделки внутри спреда или глубины книги ордеров, поддерживая активность проекта на таких агрегаторах, как CoinMarketCap и CoinGecko, без потери капитала.

Движок **Order Book Builder** постоянно размещает, сдвигает и обновляет многоуровневые ордера на покупку и продажу, создавая плотную, реалистичную книгу ордеров с органическим изменением цен, что позволяет избежать «пустого стакана», характерного для вторичных бирж.

Движок **Liquidity Provider** защищает книгу ордеров от проскальзывания, рассчитывая оптимальное распределение ликвидности на основе доступных балансов и размещая ордера в пределах заданного вами процентного спреда, чтобы покупатели и продавцы сообщества получали справедливое исполнение.

Движок **Price Watcher** отслеживает цены токенов на эталонных рынках, таких как Binance, DEX или основные торговые пары. Если внешние цены меняются, он автоматически корректирует локальные ценовые границы и коридоры ордеров, предотвращая истощение вашей ликвидности из-за хищнического межбиржевого арбитража.

## Что нового в v10.0.0

Версия 10.0.0 — это самый значительный архитектурный релиз в истории проекта, сфокусированный на надежности корпоративного уровня, безопасности и целостности цепочки поставок.

**Блокировка итераций с учетом конкурентности** решает наиболее частую причину дублирования ордеров и рассинхронизации состояния в высокочастотных ботах: перекрывающиеся тики исполнения. В v10.0 представлен `helpers/moduleIteration.js`, реализующий строгую блокировку. Если итерация уже ожидает ответа API биржи, следующий тик корректно откладывается, а не выполняется параллельно, а итерации безопасно перезапускаются из блоков `finally`, поэтому бот никогда не зависает и не падает при кратковременных разрывах сети.

Коннектор **Azbit** был полностью переписан. Теперь он использует нативную генерацию подписей HMAC-SHA256 с микросекундными метками времени, точное выравнивание десятичных знаков в соответствии со спецификациями лотов и тиков Azbit, а также мгновенную инвалидацию кэша балансов с надежным восстановлением после ошибок при ограничении частоты запросов (throttling).

**Защита от неактивности (Inactivity Guard)** предотвращает сценарий, при котором хост-сервер перезагружается или теряет связь, а рынок значительно меняется, пока бот офлайн. При запуске он проверяет метки времени «пульса» (heartbeat); если время простоя превышает заданный порог безопасности, активируется безопасный режим, чтобы предотвратить исполнение устаревших ордеров.

**Структурированная ротация логов** использует ежедневную ротацию Winston с автоматическим архивированием в gzip, настраиваемыми политиками хранения и очисткой логов, гарантируя, что API-ключи никогда не попадут в файлы журналов.

**Сквозная безопасность цепочки поставок** завершает этот релиз. Docker-образы, публикуемые в GitHub Container Registry, включают аттестации происхождения Sigstore, а пакеты npm публикуются через доверенную публикацию OpenID Connect с полной проверкой происхождения сборки на npmjs.com.

## Развертывание

Развертывание выполняется просто через глобальный npm CLI или Docker.

Для CLI убедитесь, что установлен Node.js 22+, затем выполните команды установки, инициализации и запуска:

```
# 1. Install the bot globally
npm install -g adamant-tradebot

# 2. Initialize your configuration
mm init

# 3. Configure your exchange API keys & token pair
nano config/config.default.jsonc

# 4. Start the market maker
mm start

# 5. Check live status
mm status
```

Для Docker загрузите и запустите контейнер с подтвержденным происхождением:

```
docker run -d \
  --name adamant-tradebot \
  --restart unless-stopped \
  -v $(pwd)/config:/app/config \
  -v $(pwd)/logs:/app/logs \
  ghcr.io/adamant-im/adamant-tradebot:10.0.0
```
