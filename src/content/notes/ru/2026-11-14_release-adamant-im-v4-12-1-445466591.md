Релиз v4.12.1 собран из ветки master (`074db965`) поверх версии v4.12.0 (`dfe094d3`). В рамках 68 коммитов и 12 объединенных pull-реквестов этот выпуск усиливает CSP и заголовки ответов безопасности для всех хостинг-целей, устраняет пути выполнения `eval`/`Function` при проверке Web3, обновляет схемы ADAMANT Node REST/WebSocket и минимальные версии API для node и IPFS, расширяет локализацию до восьми языков (включая арабский с поддержкой RTL), исправляет пагинацию истории криптовалютных транзакций с привязкой к конкретному узлу, добавляет элементы идентификации сборки и сброса кэша на экранах входа и настроек, а также обновляет CI-сборки для Android 16 и macOS.

### Усиление безопасности и CSP

Унифицированные заголовки ответов безопасности (`#1006`) определяют `PWA_SECURITY_HEADERS` как единый источник истины в `vite-config/plugins/cspHardeningPlugin.ts` (`frame-ancestors 'none'`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-XSS-Protection: 0`). Универсальные правила в `vercel.json` ограничивают `report-uri /api/csp-report` доменом `dev.adamant.im` и хостами предварительного просмотра Vercel, `gh-pages` исключен из развертываний Vercel, а релиз включает файлы `deploy/nginx/security-headers.conf` и `deploy/nginx/pwa-site.conf.example` с соответствующими спецификациями заголовков и развертывания.

Усиление цепочки поставок и зависимостей (`#990`, `#1029`) добавляет `node scripts/check-dependency-release-age.mjs`, `.npmrc` (`min-release-age=7`), `.github/dependency-release-age-exceptions.json` и периоды ожидания Dependabot (8 дней для npm, 7 дней для GitHub Actions) в CI безопасности.

Переход на Zod 4 без `eval` и исправление зависимостей (`#1029`) использует Zod 4 (`config({ jitless: true })` в `src/lib/configureZod.ts`) для `web3-validator` и `abitype` для `web3-eth-abi`, удаляет точки входа компилятора и расширяет фильтрацию бандла в `cspHardeningPlugin.ts` для блокировки псевдонимов `Function`. Обновлены основные зависимости среды выполнения и сборки (`dompurify`, `vue`, `vuetify`, `vue-router`, `vue-i18n`, `pinia`, `axios`, `marked`, `vite`, `electron`, `@capacitor/*`), удалены `b64-to-blob`, `file-saver` и `jest-serializer-vue`.

Изоляция учетных данных и артефактов в Playwright CI (`#999`) запрещает использование настроенных парольных фраз реальных аккаунтов в Playwright CI, отключает трассировки, скриншоты, видео и HTML/JSON-репортеры в `playwright.config.ts`, а также прекращает загрузку артефактов отчетов Playwright в `.github/workflows/playwright-ui-smoke.yml`.

Безопасность основного бандла Electron (`9cf71bc2`) динамически импортирует `electron-devtools-installer` только в режиме `DEV`, переносит его в `devDependencies` и проверяет `dist-electron/main.js` во время `electron:build:prepare` через `scripts/electron/verifyMainBundle.mjs`.

### Обновления API и схем

Схема API ADAMANT Node (`src/lib/schema/schema.json`) заменяет логический параметр `withoutDirectTransfers` на целочисленные параметры перечисления `[0, 1]` — `includeDirectTransfersInChatRooms` (`default: 1`) и `includeDirectTransfersInChats` (`default: 0`) в конечных точках `/chats/get` и получения чатов (`#984`).

Подписка ADAMANT WebSocket (`src/lib/sockets.js`) подключается при разблокировке аккаунта с использованием активных узлов ADM без задержки и передает `types` для `CHAT_TRANSACTION_TYPES` (`[Transactions.SEND, Transactions.CHAT_MESSAGE]`, типы `0` и `8`) (`#984`).

OpenAPI кошельков и минимальные версии API (`src/types/wallets/index.ts`, `adamant-wallets` `9a7df1f`) добавляют опциональный `minVersion?: string` в `Service`, повышают `adm.nodes.minVersion` до `0.10.0` для mainnet, testnet и Tor (`#984`), устанавливают `adm.services.ipfsNode.minVersion` на `0.1.0` и обновляют инициализацию `IpfsClient` в `src/lib/nodes/ipfs/index.ts` для чтения `ipfsService.minVersion` вместо `adm.services.minVersion` (`#1003`). Обновление `adamant-wallets` до `9a7df1f` перегенерирует `src/config/mainnet.json`, `src/config/testnet.json` и резервные IP в `src/lib/constants/cryptos/data.json`.

Запросы индексатора ETH PostgREST (`src/lib/nodes/eth-indexer/EthIndexerClient.ts`) гарантируют, что каждый запрос `/ethtxs` включает `limit` (`limit ?? 25`), разделяют историю нативных ETH на два ограниченных индексированных запроса (`txfrom=eq.{addr}&contract_to=eq.` и `txto=eq.{addr}&contract_to=eq.`), объединенных и дедуплицированных по `txhash` на стороне клиента, сохраняют временные границы `from`/`to` и добавляют `getTimestampGroup` для разрешения коллизий границ пагинации (`#992`).

### Локализация и поддержка RTL

Паритет восьми языков (`#998`) добавляет испанский (`es`), французский (`fr`), японский (`ja`) и арабский (`ar`), проверяет и обновляет немецкий (`de`), русский (`ru`) и упрощенный китайский (`zh`), приводит все восемь JSON-файлов локалей к формату `en.json`, извлекает жестко закодированные строки в ключи локализации и использует интерполяцию слотов `<i18n-t>` в `PasswordSetDialog.vue`.

Централизованная среда выполнения i18n и плюрализация (`#998`) консолидируют `applyLocale()` в `src/i18n.js` для синхронизации `vue-i18n`, `dayjs`, локалей Vuetify и документируют `lang`/`dir`. Исправлены `pluralRules` (включая правила для арабского, французского и русского языков для чисел `> 100`), инициализация языка браузера из `navigator.languages` при отсутствии сохраненных предпочтений и форматирование дат для арабского языка с использованием `ar-u-nu-latn`.

Полная поддержка RTL для арабского языка (`#998`) настраивает Vuetify `rtl: { ar: true }`, зеркалирует направленные иконки с помощью `a-directional-icon`, внедряет логические свойства CSS в представлениях чата/кошелька/настроек, устанавливает `dir="auto"` для сообщений пользователя и поля ввода чата, сохраняя при этом LTR-рендеринг для парольных фраз, а также добавляет `RtlUiContract.spec.js` и `chat-rtl-layout-regression.spec.ts`.

### Обмен сообщениями, история транзакций и надежность узлов

Прямые переводы ADM и синхронизация превью (`#998`) обрабатывают входящие переводы ADM типа 0 в потоках чата, чат-румов и WebSocket с дедупликацией непрочитанных сообщений, выводят состояние подтверждения при отсутствии данных, обновляют `AChatTransaction.vue`, `ChatPreview.vue`, `AdmTransaction.vue` и `TransactionListItem.vue`, а также связывают ветки PWA с `adamant-wallets/dev` или `master` через `scripts/wallets/sourceBranch.mjs`.

Ограниченная пагинация и строгая привязка к одному узлу (`#992`) обновляют пагинацию истории ETH/ERC-20, BTC (`walkHistory`, рекурсия/защита от циклов, бюджеты страниц, отслеживание `exhausted` для каждого узла) и DOGE (расчет смещения для подтвержденных не-`PENDING` транзакций, перечитывание перекрытий, устойчивость к double-spend), чтобы каждое окно запроса оставалось привязанным к активному индексатору без веерной рассылки по разным операторам. Загрузчики истории DASH обернуты в `try ... finally`, добавлен `src/lib/live-history-pagination.env.spec.ts`.

Санитизация модуля IndexedDB (`#992`) вводит `toPersistedModule` в `src/lib/idb/state.js`, чтобы сохраненные крипто-модули исключали `transactions` и сбрасывали `bottomReached`, `oldTxState`, `newTxCatchUp` и `historySession` при сохранении.

HTTP-вложения и уведомления (`#989`) добавляют резервный вариант мультихэша SHA-256 `@noble/hashes` в `src/lib/files/ipfs.ts` при отсутствии `crypto.subtle` на обычных HTTP-источниках, безопасно разрешают `$t` в `src/lib/notifications.js` и сохраняют экземпляр `Notifications` в `src/App.vue` для очистки при размонтировании.

### Идентификация сборки, сетевые конфигурации и упаковка для платформ

Идентификация сборки входа и настроек (`#996`) внедряет санированные метаданные сборки (`version`, `branch`, `commit`, `prNumber`, `author`, `buildDate`, `isTestnet`) через `vite-config/plugins/buildInfoPlugin.ts` (`virtual:adamant-build-info`), отображает `BuildInfo.vue` и `BuildInfoDialog.vue` на страницах `/login` и `/options`, предоставляет действие принудительного обновления Service Worker + CacheStorage (с сохранением учетных данных/данных аккаунта) и помечает сборки testnet специальным чипом и угловым бейджем.

Изолированные сетевые конфигурации (`#986`) заменяют `development.json` и `production.json` общим `mainnet.json`, упаковывают единую конфигурацию через `virtual:adamant-network-config`, обеспечивают строгую проверку режима Vite, отклоняют неожиданные JSON-файлы в `src/config` и утечки конечных точек между сетями, принудительно выполняют `npm run wallets:data:check` в CI-воркфлоу и консолидируют документацию для участников в `CONTRIBUTING.md`.

Android 16 и Electron macOS CI (`b378c2f8`, `#1035`) повышают `compileSdkVersion`/`targetSdkVersion` для Android до `36`, `minSdkVersion` до `24`, AGP до `8.13.0`, Gradle до `8.14.3` и `cordovaAndroidVersion` до `14.0.1` (`versionCode` `41201`). Метаданные версии обновлены до `4.12.1`. Релиз устанавливает `APPLE_NOTARIZE: 'false'` в `.github/workflows/electron-mac.yml`, сохраняя подпись Developer ID и документируя инструкции **Open Anyway** (Открыть в любом случае) для Gatekeeper в `CONTRIBUTING.md`.

### Критические изменения

Минимальные версии API узлов и сервисов (`#984`, `#1003`, `98fc3815`) теперь исключают узлы ADM ниже API `0.10.0` из всех запросов ADM, помечают узлы IPFS ниже `0.1.0` как `unsupported_version` и заменяют старые резервные IP-адреса (`endless`, `testnode1`, `testnode3`, `dschubba`) на новые альтернативы.

Нотаризация macOS CI отключена (`#1035`). Артефакты macOS поставляются с подписью Developer ID без нотаризации Apple (`APPLE_NOTARIZE: 'false'`), поэтому Gatekeeper требует однократного разрешения приложения через **Системные настройки → Конфиденциальность и безопасность → Открыть в любом случае**.

Строгие заголовки ответов CSP (`#1006`) принудительно применяются через универсальные правила `vercel.json` и `deploy/nginx/security-headers.conf` с `frame-ancestors 'none'`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer` и `X-XSS-Protection: 0`.

Файлы конфигурации `development.json` и `production.json` удалены (`#986`). Импорт конфигурации во время выполнения продолжается через `@/config` на основе `src/config/mainnet.json`, а неподдерживаемые режимы Vite или неожиданные JSON-файлы в `src/config` приводят к ошибке сборки.

Менеджер пакетов зафиксирован на версии `npm@12.2.2` с 7-дневным карантином npm и проверкой Zod 4 (`#1029`). Версии зависимостей младше 7 дней вызывают ошибку Security CI, если на них не распространяется исключение, а ошибки формата Web3 Zod скрывают значения необработанных входных данных.

Целевые версии Android 16 (`b378c2f8`) повышают `minSdkVersion` с `23` до `24` (Android 7.0), при этом `compileSdkVersion` и `targetSdkVersion` установлены на `36`.

Санитизация крипто-состояния IndexedDB (`#992`) означает, что сохраненные крипто-модули исключают `transactions` и сбрасывают сессионные курсоры пагинации при сохранении.
