ADAMANT Explorer v2.0.0 — это первый стабильный релиз после версии v1.3.0. Он модернизирует фронтенд, бэкенд, систему мониторинга в реальном времени, механизмы безопасности, зависимости, тесты и эксплуатационную документацию, сохраняя при этом существующие URL-адреса общедоступных страниц и глубокие ссылки.

Фронтенд был переписан с использованием Vue 3, Pinia, Vue Router 5 и Vite 8, заменив прежний стек AngularJS, Bootstrap 3 и Webpack. Все общедоступные страницы Explorer теперь поддерживают адаптивную верстку для настольных компьютеров, планшетов и мобильных устройств, включают постоянные светлую и темную темы, доступные элементы управления, мобильные карточки транзакций, более безопасные подсказки и улучшенную обратную связь при копировании. Добавлена контекстная семантика транзакций для переводов, голосований и отмены голосов, операций DApp, активности на биржах и приветственных бонусов.

На стороне бэкенда доступ к ADAMANT Node был перестроен на базе `adamant-api` 3.1.0 с внедрением контроля готовности, отказоустойчивости, ограниченной пагинации, нормализованных ошибок и разделения слоев запросов и обработчиков. Сохранены 12 маршрутов с тем же источником (same-origin), требуемых для UI Explorer, и добавлен новый маршрут `GET /api/networkHealth`. Внедрены строгая валидация маршрутов и запросов, детерминированная сортировка транзакций, исправленная фильтрация переводов, пагинация для топовых аккаунтов, подтверждения в реальном времени и форматирование ADM с полной точностью. Redis теперь является опциональным для базового обслуживания, при этом сохранены устойчивое кэширование API, а также динамическая статистика блоков и узлов.

Мониторинг в реальном времени был стабилизирован для заголовков, монитора делегатов, монитора сети и жизненного цикла Activity Graph Socket.IO с использованием сериализованного опроса и ограниченных повторных попыток. Добавлены обновление страниц на основе блоков и ограниченное REST-подтверждение для компактных WebSocket-уведомлений о блоках. Улучшены расписания делегатов, состояния форжинга, вознаграждения, комиссии, статистика узлов, сортировка версий и поведение на границах раундов. Интеграция Freegeoip была заменена на опциональную геолокацию узлов через GeoJS, а также внедрен кэшируемый прокси-сервер тайлов OpenStreetMap с ограничением частоты запросов и проверкой источника.

Улучшения безопасности и надежности включают удаление подстановочных знаков CORS и 16 устаревших конечных точек API Explorer. Добавлены ограничение частоты запросов API с учетом прокси, проверка доверенных прокси, заголовки безопасности, ограниченный CSP, стабильные сообщения об ошибках и явные тайм-ауты HTTP. Журналы запросов минимизированы за счет исключения строк запроса, а данные из недоверенных узлов, пиров, прокси, Redis, геолокации и источников браузера проходят валидацию. Добавлены модель угроз репозитория, аудит безопасности и надежности, а также обширное модульное покрытие для публичных интерфейсов и состояния мониторинга.

Поддерживаемая среда выполнения обновлена до Node.js `^22.18.0 || >=24.11.0`. Обновлены Express, Redis, Socket.IO, Axios, Vue, Vite, Pinia, Vue Router, ESLint, Mocha, Chai, Supertest и остальные зависимости. Удалены устаревшие Grunt, Protractor, Cucumber, Jenkins, Travis, Webpack/Babel, а также неактуальные интеграции Market Watcher и бирж. Добавлены 43 модульных теста только для Node, обновлены фикстуры для тестовой сети (Testnet), расширено покрытие API, безопасности, планирования, формирования данных и вспомогательных утилит фронтенда. Файл `README.md` обновлен с учетом актуальных руководств для участников и операторов AI-агентов.

Процесс валидации включал прохождение проверок ESLint и Prettier, сборку для продакшена с трансформацией 6 337 модулей, набор из 226 модульных тестов, набор из 41 API-теста для тестовой сети на выпущенном дереве исходного кода, аудит зависимостей с отчетом о 0 уязвимостей, а также smoke-тесты браузера, охватывающие 13 маршрутов при различных разрешениях экрана без ошибок в консоли и горизонтальной прокрутки.

### Критические изменения

Версия Node.js должна быть обновлена до `^22.18.0 || >=24.11.0`. Конфигурацию развертывания следует создать на основе нового файла `config.default.jsonc`, проверив параметры `nodes_adm`, `trustedProxies`, `redis`, `geoLocation`, `exchangeRates` и `log_level`. Требуется ADAMANT Node v0.10.2 или новее; предпочтительно использование нескольких независимо работающих узлов HTTPS. Удаленную интеграцию Freegeoip следует заменить на опциональную конфигурацию GeoJS; отключение геолокации сохраняет доступность данных об узлах и именах хостов без отображения карт или флагов стран. Внешним потребителям удаленных маршрутов API Explorer следует перейти на `adamant-api-jsclient`, а для оперативного мониторинга использовать `GET /api/networkHealth`. Путь `/osm-tiles/` (same-origin) должен быть разрешен в правилах обратного прокси-сервера и брандмауэра. Игнорируемый бандл `public/` должен собираться во время развертывания с помощью `npm run build`. Для разработки используйте `npm run dev` для объединенного стека бэкенда и Vite или `npm run dev:frontend` только для Vite. Существующие маршруты страниц Explorer и глубокие ссылки остаются совместимыми, а Redis рекомендуется, но больше не является обязательным для базового HTTP-обслуживания и отдачи статики.
