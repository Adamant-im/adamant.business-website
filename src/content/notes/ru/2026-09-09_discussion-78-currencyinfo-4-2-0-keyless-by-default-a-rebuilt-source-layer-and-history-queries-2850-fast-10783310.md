## Обзор обновления

Мы рады представить **Currencyinfo 4.2.0**. Этот релиз сосредоточен на повышении безопасности, упрощении конфигурации и радикальном увеличении скорости работы с историческими данными. Обновление уже доступно для использования в **ADAMANT Tradebot**.

## Основные изменения

### Режим без ключей (Keyless) по умолчанию
Теперь для работы с большинством публичных данных API не требуется обязательная настройка API-ключей. Это упрощает развертывание бота через **Docker** или **npm** и снижает риски утечки учетных данных. Если вам по-прежнему необходимы расширенные лимиты, вы можете настроить ключи в файле `config.default.jsonc`.

### Переработанный уровень источников данных
Мы полностью переписали слой взаимодействия с внешними источниками. Это позволило:
* Устранить узкие места при параллельных запросах.
* Повысить стабильность при работе с биржами, такими как **Azbit**, **P2PB2B**, **StakeCube**, **Coinstore**, **FameEX** и **NonKYC**.
* Улучшить обработку ошибок при сетевых сбоях.

### Производительность: запросы истории в 2850 раз быстрее
Благодаря оптимизации индексации в **MongoDB** и переработке логики запросов в `modules/commands/`, время выполнения операций с историей цен сократилось на несколько порядков. То, что раньше занимало секунды, теперь выполняется практически мгновенно.

## Как обновиться

Для обновления вашего экземпляра **adamant-tradebot** выполните стандартные команды:

1. Остановите бота: `mm off`
2. Обновите зависимости: `npm install` (или пересоберите образ **Docker** через **Compose**)
3. Проверьте конфигурацию: `mm doctor`
4. Запустите бота: `mm on`
