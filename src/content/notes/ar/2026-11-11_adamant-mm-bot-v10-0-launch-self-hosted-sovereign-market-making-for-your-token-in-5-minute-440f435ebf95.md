## مشكلة سيولة العملات الرقمية

يواجه مؤسسو مشاريع العملات الرقمية حقيقة قاسية عند الإدراج في منصة مركزية: العملة التي تفتقر إلى السيولة تُعد ميتة فعلياً. فبدون سيولة مستمرة وحجم تداول مرئي، تفقد المشاريع تصنيفاتها في مجمعات البيانات، وتوسع روبوتات المراجحة (arbitrage bots) فروق الأسعار، ويغادر المتداولون الأفراد بسبب الانزلاق السعري (slippage). الاستجابة التقليدية هي توظيف وكالة لصناعة السوق، ودفع رسوم شهرية تتراوح بين 5,000 إلى 30,000 دولار أو أكثر، وتسليم حضانة العملات والعملات المستقرة إلى حسابات طرف ثالث. وقد شهدت مشاريع كثيرة قيام صناع السوق ببيع عملات الخزينة أو اختفائهم أثناء فترات تقلب السوق.

البديل هو صناعة سوق سيادية ومستضافة ذاتياً. مع ADAMANT TradeBot v10.0.0، يمكنك تشغيل صانع سوق مؤتمت بالكامل وبمستوى مؤسسي على خادم افتراضي (VPS) بتكلفة 5 دولارات شهرياً أو عبر حاوية Docker في أقل من خمس دقائق، دون نقل حضانة عملاتك إلى أي جهة.

## تصميم غير وصائي (Non-Custodial)

الفلسفة الجوهرية هي السيادة المالية الكاملة. يعمل ADAMANT TradeBot بالكامل في بيئتك الخاصة ذات المستأجر الواحد. يتطلب الروبوت فقط أذونات قراءة وتداول أساسية عبر واجهة برمجة التطبيقات (API)؛ أما أذونات السحب فهي معطلة ومحظورة تماماً. أنت لا ترسل أبداً عملات أو عملات مستقرة إلى ADAMANT أو إلى أي وكالة أو عقد ذكي. لا تغادر العملات حسابك في المنصة أبداً، ويتم تنفيذ جميع حسابات الأوامر، وفروق الأسعار الخوارزمية، وتسويات الأرصدة محلياً. يمكنك تعديل فروق الأسعار، وأهداف الحجم، وممرات الأسعار أثناء التشغيل عبر واجهة ADAMANT Messenger أو واجهة برمجة تطبيقات الويب (WebUI API).

## أربع محركات خوارزمية

تأتي النسخة مفتوحة المصدر مزودة بأربعة محركات متزامنة تتعامل مع كل أبعاد صناعة السوق.

محرك **Trader** يولد حجماً ثابتاً وطبيعياً من خلال تنفيذ صفقات ذاتية المطابقة ضمن فروق الأسعار أو عمق سجل الأوامر، مما يحافظ على نشاط المشروع في مجمعات البيانات مثل CoinMarketCap و CoinGecko دون استنزاف رأس المال.

محرك **Order Book Builder** يقوم باستمرار بوضع وتحريك واستبدال أوامر الشراء والبيع المتدرجة، مما ينتج سجل أوامر كثيفاً وواقعياً مع تباين سعري عضوي، متجنباً مظهر "السلم الفارغ" الشائع في المنصات الثانوية.

محرك **Liquidity Provider** يدافع عن سجل الأوامر ضد الانزلاق السعري، حيث يحسب التوزيع الأمثل للسيولة من الأرصدة المتاحة ويضع أوامر عمق ضمن نسبة فرق السعر المحددة لضمان تنفيذ عادل للمشترين والبائعين في المجتمع.

محرك **Price Watcher** يراقب أسعار العملات عبر أسواق مرجعية مثل Binance أو المنصات اللامركزية (DEXs) أو أزواج التداول الرئيسية. إذا تحركت الأسعار الخارجية، يقوم المحرك تلقائياً بتعديل حدود الأسعار المحلية وممرات الأوامر لمنع استنزاف سيولتك بسبب المراجحة المفترسة عبر المنصات.

## ما الجديد في الإصدار 10.0.0

يُعد الإصدار 10.0.0 أهم إصدار معماري في تاريخ المشروع، حيث يركز على موثوقية المؤسسات، والسلامة، ونزاهة سلسلة التوريد.

تعالج **آلية قفل التكرار الآمنة للتزامن (Concurrency-safe iteration locking)** السبب الأكثر شيوعاً للأوامر المكررة وحالة عدم التزامن في الروبوتات عالية التردد: وهي تداخل دورات التنفيذ. يقدم الإصدار 10.0 ملف `helpers/moduleIteration.js` الذي يطبق قفلاً صارماً. إذا كان التكرار ينتظر بالفعل استجابة من واجهة برمجة تطبيقات المنصة، يتم تأجيل الدورة التالية بدلاً من تنفيذها بشكل متزامن، ويتم إعادة جدولة التكرارات بأمان من كتل `finally` لضمان عدم تعليق الروبوت أو انهياره أثناء انقطاعات الشبكة العابرة.

تمت إعادة كتابة **موصل Azbit** بالكامل. وهو يستخدم الآن توليد توقيع HMAC-SHA256 أصلي مع طوابع زمنية بالميكروثانية، ومحاذاة دقيقة للكسور العشرية تلتزم بمواصفات Lot و Tick الخاصة بـ Azbit، وإبطال فوري لذاكرة التخزين المؤقت للأرصدة مع استرداد قوي للأخطاء عند تقييد طلبات HTTP.

يحمي **حارس عدم النشاط (Inactivity Guard)** من سيناريو إعادة تشغيل الخادم أو فقدان الاتصال وتحرك السوق بشكل كبير أثناء توقف الروبوت. عند التشغيل، يتحقق الروبوت من الطوابع الزمنية لنبضات القلب؛ وإذا تجاوز وقت التوقف حد الأمان الخاص بك، فإنه يفعل وضع الأمان لمنع تنفيذ أوامر قديمة.

يستخدم **تدوير السجلات المهيكل (Structured log rotation)** نظام Winston اليومي مع أرشفة gzip التلقائية، وسياسات استبقاء قابلة للتكوين، وتسجيل بيانات مُنقى لضمان عدم تسرب مفاتيح واجهة برمجة التطبيقات إلى ملفات السجلات.

تكتمل هذه الإصدارة بـ **أمن سلسلة التوريد الشامل**. تتضمن صور Docker المنشورة على GitHub Container Registry شهادات مصدر Sigstore، ويتم نشر حزم npm عبر النشر الموثوق لـ OpenID Connect مع إثبات بناء كامل على npmjs.com.

## النشر

النشر مباشر وبسيط سواء عبر npm CLI العالمي أو Docker.

بالنسبة لنهج CLI، تأكد من تثبيت Node.js 22+، ثم قم بتشغيل أوامر التثبيت والتهيئة والبدء:

```
# 1. Install the bot globally
npm install -g adamant-tradebot

# 2. Initialize your configuration
mm init

# 3. Configure your exchange API keys & token pair
nano config/config.default.jsonc

# 4. Start the market maker
mm start

# 5. Check live status
mm status
```

بالنسبة لـ Docker، قم بسحب وتشغيل الحاوية الموثقة المصدر:

```
docker run -d \
  --name adamant-tradebot \
  --restart unless-stopped \
  -v $(pwd)/config:/app/config \
  -v $(pwd)/logs:/app/logs \
  ghcr.io/adamant-im/adamant-tradebot:10.0.0
```
