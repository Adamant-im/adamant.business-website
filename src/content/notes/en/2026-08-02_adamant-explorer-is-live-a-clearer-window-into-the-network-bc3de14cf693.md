The new ADAMANT Explorer is live at explorer.adamant.im, offering a faster, clearer way to follow the network in motion. A blockchain explorer is where network data becomes understandable, transforming opaque identifiers into readable blocks, transactions, and accounts. The ADAMANT Explorer was rebuilt around the idea that users should be able to verify network activity without unnecessary friction.

The home screen displays Mainnet status, current chain height, and ADM supply. A "Latest operations" stream turns fresh on-chain activity into a readable format, making transfers, messages, votes, and registrations easier to recognize at a glance. A unified search field allows users to look up blocks, transactions, addresses, or delegates, routing them directly to the relevant record without needing to decode URL structures.

The redesigned block list presents essential orientation data, including IDs, heights, timestamps, transaction counts, forging delegates, amounts, and forged rewards. Detail views keep the complete record available for deeper investigation. This approach makes important context visible while keeping the original chain data accessible.

ADAMANT is community-operated infrastructure, and the Explorer is open source, built on public ADAMANT node interfaces. It combines live network updates with API-backed detail views, ensuring the changing network remains readable while the node stays the authority for blockchain state. This provides a public window into the network operated by independent nodes, rather than relying on a private dashboard or delayed data feed.
