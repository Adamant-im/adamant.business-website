Release v4.12.1 ships from master (`074db965`) on top of v4.12.0 (`dfe094d3`). Across 68 commits and 12 merged pull requests, this release hardens CSP and security response headers across hosting targets, eliminates runtime `eval`/`Function` paths in Web3 validation, updates ADAMANT Node REST/WebSocket schemas and minimum node/IPFS API versions, expands localization to eight languages including Arabic RTL, repairs bounded crypto transaction history pagination with strict single-node affinity, adds build identity and cache reset controls on the login and settings screens, and updates Android 16 and macOS CI packaging.

### Security & CSP hardening

Unified security response headers (`#1006`) define `PWA_SECURITY_HEADERS` as a single source of truth in `vite-config/plugins/cspHardeningPlugin.ts` (`frame-ancestors 'none'`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-XSS-Protection: 0`). Catch-all rules in `vercel.json` restrict `report-uri /api/csp-report` to `dev.adamant.im` and Vercel preview hosts, `gh-pages` is excluded from Vercel deployments, and the release ships `deploy/nginx/security-headers.conf` and `deploy/nginx/pwa-site.conf.example` with corresponding header/deployment specs.

Supply-chain and dependency hardening (`#990`, `#1029`) adds `node scripts/check-dependency-release-age.mjs`, `.npmrc` (`min-release-age=7`), `.github/dependency-release-age-exceptions.json`, and Dependabot cooldowns (8 days for npm, 7 days for GitHub Actions) in Security CI.

Eval-free Zod 4 and dependency remediation (`#1029`) uses Zod 4 (`config({ jitless: true })` in `src/lib/configureZod.ts`) for `web3-validator` and `abitype` for `web3-eth-abi`, removes compiler entry points, and expands the bundle gate in `cspHardeningPlugin.ts` against `Function` aliases. Core runtime and build dependencies are updated (`dompurify`, `vue`, `vuetify`, `vue-router`, `vue-i18n`, `pinia`, `axios`, `marked`, `vite`, `electron`, `@capacitor/*`), and `b64-to-blob`, `file-saver`, and `jest-serializer-vue` are removed.

Playwright CI credential and artifact isolation (`#999`) rejects configured live account passphrases in Playwright CI, disables CI traces, screenshots, videos, and HTML/JSON reporters in `playwright.config.ts`, and stops uploading Playwright report artifacts in `.github/workflows/playwright-ui-smoke.yml`.

Electron main-bundle safety (`9cf71bc2`) dynamically imports `electron-devtools-installer` only in `DEV` mode, moves it to `devDependencies`, and verifies `dist-electron/main.js` during `electron:build:prepare` via `scripts/electron/verifyMainBundle.mjs`.

### API & schema updates

The ADAMANT Node API schema (`src/lib/schema/schema.json`) replaces the boolean `withoutDirectTransfers` with integer enum `[0, 1]` parameters `includeDirectTransfersInChatRooms` (`default: 1`) and `includeDirectTransfersInChats` (`default: 0`) on `/chats/get` and chat retrieval endpoints (`#984`).

The ADAMANT WebSocket subscription (`src/lib/sockets.js`) connects on account unlock using active ADM nodes without delay and emits `types` for `CHAT_TRANSACTION_TYPES` (`[Transactions.SEND, Transactions.CHAT_MESSAGE]`, types `0` and `8`) (`#984`).

Wallet OpenAPI and minimum API versions (`src/types/wallets/index.ts`, `adamant-wallets` `9a7df1f`) add optional `minVersion?: string` to `Service`, raise `adm.nodes.minVersion` to `0.10.0` across mainnet, testnet, and Tor (`#984`), set `adm.services.ipfsNode.minVersion` to `0.1.0`, and update `IpfsClient` instantiation in `src/lib/nodes/ipfs/index.ts` to read `ipfsService.minVersion` instead of `adm.services.minVersion` (`#1003`). The `adamant-wallets` update to `9a7df1f` regenerates `src/config/mainnet.json`, `src/config/testnet.json`, and `src/lib/constants/cryptos/data.json` fallback IPs.

ETH PostgREST indexer queries (`src/lib/nodes/eth-indexer/EthIndexerClient.ts`) ensure every `/ethtxs` request includes `limit` (`limit ?? 25`), split native ETH history into two bounded indexed queries (`txfrom=eq.{addr}&contract_to=eq.` and `txto=eq.{addr}&contract_to=eq.`) merged and deduplicated by `txhash` client-side, preserve `from`/`to` time bounds, and add `getTimestampGroup` to resolve pagination boundary collisions (`#992`).

### Localization & RTL support

Eight-language parity (`#998`) adds Spanish (`es`), French (`fr`), Japanese (`ja`), and Arabic (`ar`), reviews and updates German (`de`), Russian (`ru`), and Simplified Chinese (`zh`), aligns all eight locale JSON files to `en.json`, extracts hardcoded strings into locale keys, and uses `<i18n-t>` slot interpolation in `PasswordSetDialog.vue`.

Centralized i18n runtime and pluralization (`#998`) consolidates `applyLocale()` in `src/i18n.js` to synchronize `vue-i18n`, `dayjs`, Vuetify locales, and document `lang`/`dir`. It corrects `pluralRules` (including Arabic, French, and Russian `> 100` teen rules), initializes browser language locally from `navigator.languages` when no saved preference exists, and formats Arabic dates using `ar-u-nu-latn`.

Full Arabic RTL layout (`#998`) configures Vuetify `rtl: { ar: true }`, mirrors directional icons with `a-directional-icon`, adopts CSS logical properties across chat/wallet/settings views, sets `dir="auto"` on user-authored messages and the chat composer while preserving LTR rendering for passphrases, and adds `RtlUiContract.spec.js` and `chat-rtl-layout-regression.spec.ts`.

### Messaging, transaction history & node reliability

Direct ADM transfers and preview sync (`#984`) ingest incoming type-0 ADM transfers across chat, chatroom, and WebSocket flows with deduplicated unread handling, derive fallback confirmation state when omitted, update `AChatTransaction.vue`, `ChatPreview.vue`, `AdmTransaction.vue`, and `TransactionListItem.vue`, and map PWA branches to `adamant-wallets/dev` vs `master` via `scripts/wallets/sourceBranch.mjs`.

Bounded pagination and strict single-node affinity (`#992`) update ETH/ERC-20, BTC (`walkHistory`, recursion/cycle guards, page budgets, per-node `exhausted` tracking), and DOGE (confirmed non-`PENDING` offset calculation, overlap re-reading, double-spend tolerance) history pagination so every request window stays pinned to the active indexer without cross-operator address fan-out. DASH history loaders are wrapped in `try ... finally`, and `src/lib/live-history-pagination.env.spec.ts` is added.

IndexedDB module sanitization (`#992`) introduces `toPersistedModule` in `src/lib/idb/state.js` so persisted crypto modules omit `transactions` and reset `bottomReached`, `oldTxState`, `newTxCatchUp`, and `historySession` on save.

HTTP attachments and notifications (`#989`) add an `@noble/hashes` SHA-256 multihash fallback in `src/lib/files/ipfs.ts` when `crypto.subtle` is absent on plain HTTP origins, resolve `$t` safely in `src/lib/notifications.js`, and preserve the `Notifications` instance in `src/App.vue` for unmount cleanup.

### Build identity, network configs & platform packaging

Login and Settings build identity (`#996`) injects sanitized build metadata (`version`, `branch`, `commit`, `prNumber`, `author`, `buildDate`, `isTestnet`) via `vite-config/plugins/buildInfoPlugin.ts` (`virtual:adamant-build-info`), renders `BuildInfo.vue` and `BuildInfoDialog.vue` on `/login` and `/options`, provides a Service Worker + CacheStorage Force refresh action (preserving stored credentials/account data), and marks testnet builds with a hero chip and corner badge.

Isolated network configurations (`#986`) replace `development.json` and `production.json` with shared `mainnet.json`, bundle a single config via `virtual:adamant-network-config`, enforce strict Vite mode validation, reject unexpected JSON files in `src/config` and cross-network endpoint leaks, enforce `npm run wallets:data:check` in CI workflows, and consolidate contributor/build documentation into `CONTRIBUTING.md`.

Android 16 and Electron macOS CI (`b378c2f8`, `#1035`) raise Android `compileSdkVersion`/`targetSdkVersion` to `36`, `minSdkVersion` to `24`, AGP to `8.13.0`, Gradle to `8.14.3`, and `cordovaAndroidVersion` to `14.0.1` (`versionCode` `41201`). Version metadata bumps to `4.12.1`. The release sets `APPLE_NOTARIZE: 'false'` in `.github/workflows/electron-mac.yml` while keeping Developer ID signing and documenting Gatekeeper **Open Anyway** instructions in `CONTRIBUTING.md`.

### Breaking changes

Minimum node and service API versions (`#984`, `#1003`, `98fc3815`) now exclude ADM nodes below API `0.10.0` from all ADM requests, mark IPFS nodes below `0.1.0` as `unsupported_version`, and replace older fallback IP addresses (`endless`, `testnode1`, `testnode3`, `dschubba`) with relocated alternatives.

macOS CI notarization is disabled (`#1035`). macOS artifacts ship Developer ID signed without Apple notarization (`APPLE_NOTARIZE: 'false'`), so Gatekeeper requires allowing the app once via **System Settings → Privacy & Security → Open Anyway**.

Strict CSP response headers (`#1006`) are enforced via catch-all `vercel.json` rules and `deploy/nginx/security-headers.conf` with `frame-ancestors 'none'`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, and `X-XSS-Protection: 0`.

The `development.json` and `production.json` config files are removed (`#986`). Runtime config imports continue through `@/config` backed by `src/config/mainnet.json`, and unsupported Vite modes or unexpected JSON files in `src/config` fail builds.

The package manager is pinned to `npm@12.2.2` with a 7-day npm quarantine and Zod 4 validation (`#1029`). Dependency versions younger than 7 days fail Security CI unless exempted, and Web3 Zod format errors omit raw input values.

Android 16 targets (`b378c2f8`) raise `minSdkVersion` from `23` to `24` (Android 7.0), with `compileSdkVersion` and `targetSdkVersion` set to `36`.

IndexedDB crypto state sanitization (`#992`) means persisted crypto modules omit `transactions` and reset pagination session cursors on save.
